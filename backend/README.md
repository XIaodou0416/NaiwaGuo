# 奶蛙统计后台

扩展现有 Naiwa Python 服务，在同一 HTTPS 管理台显示“奶蛙统计”，支持奶蛙账号封禁。不改变网易云客户端接口。

## 文件与部署

- guo_backend.py：独立 SQLite 数据库、上报/删除接口、需要原管理员会话的查询接口。
- guo-admin.js：沿用现有管理台样式和登录状态，不含管理密码或客户端密钥。
- install_into_naiwa.py：检查启动入口和静态资源路由，生成部署前快照；应先在副本上运行现有 Naiwa 回归，再安装并重启原服务。

2026-11-05 部署到原 Naiwa 服务；部署前保存代码和数据库一致性快照，保存在服务器 naiwa-releases 目录。服务继续监听原本的回环地址，通过已有 HTTPS 反向代理提供服务。

本目录不包含原后台的管理员密码、签名私钥或真实数据库。生产凭据只在服务器维护。源码 ZIP 只备份代码；运行数据应另用 SQLite backup API 备份 guo.sqlite3，不能直接复制正在写入的数据库文件。

## 数据与口径

上报接口：POST /api/guo/v1/usage。客户端启动后自动发送 installation、secret、hongguo_id、plugin_version、host_version、system_version、schema_version，不设统计开关、说明页面或说明弹窗。secret 是每次安装随机生成的写入/删除凭据，数据库只保存 SHA-256；客户端不会包含服务器账号或管理员密码。

网络失败不限制普通用户，已缓存封禁按账号保留。每次启动、进入设置和前台账号变化时可上报，活跃时约每分钟检查一次；统计数不是实时在线人数。POST /api/guo/v1/forget 供运维及合成安装测试清理，验证该安装随机凭据后删除对应安装、账号关联和日活记录，不能删除 ID 封禁。

## 封禁管理

管理台可输入红果 ID 封禁、添加备注，也可在用户行封禁或解除。GET /api/admin/guo/bans 查询封禁列表；POST /api/admin/guo/ban 接收 hongguo_id、blocked 布尔值和可选 note（最多 200 字），必须有原管理员会话、同源 Origin 和 CSRF 令牌。独立封禁表和操作记录写入 guo.sqlite3，封禁不随安装记录删除。

上报响应包含当前 hongguo_id 和 blocked，客户端只接受与请求账号相符的判断；进入封禁状态会暂停外观、布局、图标、字体与调试效果，并将设置灰显，解除后读取原配置。切换账号时按新账号重新判断。0.1.0 及更早客户端不处理封禁响应，无法追溯限制旧版；红果 ID 由客户端读取，不能抵御篡改客户端伪造身份或绕过检查。离线未曾查询到的封禁只能在下次成功联网后生效。

按客户端提供的红果 ID 去重，不构成红果平台身份认证，无法阻止恶意客户端伪造统计；未登录或接口暂不可读时 ID 为空，只统计安装。重新安装可能生成新安装编号。日趋势保留 90 天，180 天不活跃安装删除。版本分布按近 30 天活跃安装统计。

管理接口 GET /api/admin/guo/stats 和 /api/admin/guo/users 需要原后台管理员会话；凭据摘要不出现在返回值中。只允许参数化 SQL、限制请求大小和频率。原服务及反向代理的运维访问日志沿用既有策略。

## 验证

~~~sh
python3 -m unittest discover -s backend -v
~~~

独立测试验证去重、版本分布、未登录统计、拒绝非法输入、删除凭据与级联删除；HTTP 集成测试需要已有 Naiwa test_server.py 的隔离测试环境。插件的真实 HTTPS 联调使用合成账号，完成后删除测试安装，不读取真实用户记录。
