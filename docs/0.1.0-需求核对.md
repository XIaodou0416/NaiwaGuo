# 0.1.0 需求核对

| 要求 | 实现 |
| --- | --- |
| 恢复上一版图标并改黑色 | 取消彩色方块，恢复线性 SF Symbols，浅色黑色、深色白色。 |
| 移除墨绿强调色 | 开关、滑块、导航、搜索和描边使用黑白自适应配色，不修改宿主主题或用户自定义视频图标。 |
| 重新分类面板 | 播放与画面、底栏设置、玻璃与面板、图标与文字、备份与数据、工具与诊断；搜索继续定位具体项目。 |
| 清理与流畅性 | 分类数据只构建一次，复用分类单元格；移除图标位图绘制和多余单元格分配；开关只刷新对应效果；旧诊断测试代码不进入设备构建，删掉重复说明注释并保留版权与复杂行为说明。 |
| 接入原 naiwa 后台 | 同一 HTTPS 域名和管理台增加“奶蛙统计”；沿用管理员登录，使用独立 guo.sqlite3；原网易云接口保持原路由。 |
| 使用人数和版本 | 启动后自动上报随机安装编号、红果 ID、红果版本、奶蛙版本与 iOS 版本。按红果 ID 去重人数，未登录只计安装；不读取宿主登录凭据或观看内容。 |
| 自动统计 | 不设统计开关，不限制任何插件功能。首次打开设置显示一次数据说明，说明页保留字段和保留期限；网络异常安静重试。 |
| 备份与恢复 | .naiwaguo 文件包含设置、自定义图标和当前字体；严格校验、恢复前确认，仅替换插件设置。文件读写和字体导入在后台执行，不备份账号和统计凭据。 |
| 私人维护 | 安装包与完整源码分开；独立新版本源码快照，不覆盖旧版本。 |

系统最低 iOS 15。模拟器与设备构建结果见 [VALIDATION.md](VALIDATION.md)，不代表用户真机验收。
