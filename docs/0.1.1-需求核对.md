# 0.1.1 需求核对

| 要求 | 实现 |
| --- | --- |
| 删除使用统计与隐私 | 删除页面、菜单、搜索路由和首次说明弹窗；保留后台自动统计。 |
| 备份入口少点一次 | 首页点击“备份与恢复”直接显示原来的导出、恢复操作；不重做界面和文件格式。 |
| 封禁红果 ID | 原 Naiwa 后台支持按 ID 封禁、备注和解除，写入独立封禁表与操作记录；管理员登录、同源和 CSRF 校验。 |
| 被封禁不能用 | 客户端检测到封禁后暂停设置产生的效果，面板灰显、禁止点击并提示“已被拉黑”；保留用户配置，解除后恢复。缓存按 ID 区分，不影响其他账号。 |
| 开启功能数量 | 首页副标题显示“已开启 N 项功能”；返回设置刷新，被封禁时为 0，不把赞助偏好、尺寸数值或迁移标志当作开启的功能。 |
| 双指长按入口 | 普通应用窗口默认安装双指长按识别器，约 0.65 秒触发，不增加开关；不取消宿主触摸，允许并行识别，重复安装和触发不叠加。被封禁账号仍可打开灰色面板。 |
| 版本备份 | 仓库私有，0.1.1 独立完整源码备份，不覆盖旧归档；客户端不包含服务器和管理员凭据。 |

封禁需要 0.1.1 客户端处理服务端响应。旧版、篡改客户端或客户端提供的伪造 ID 无法由此机制可靠限制；未联网获取过的封禁下次联网才生效。验证和真机边界见 [VALIDATION.md](VALIDATION.md)。
