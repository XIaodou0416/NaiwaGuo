# 0.0.5 需求核对

本地候选版，2026-11-05。修复后的红果真机效果仍需反馈。

| 需求 | 实现与验证 |
| --- | --- |
| 系统版本自动开启液态兼容 | iOS 26+ 自动启用兼容层，低版本退出；各功能开关首次默认关闭，已保存设置保留。 |
| 底栏选中/未选中颜色恢复 | 三种内容模式、浅深色、收缩圆钮、颜色选择器实时更新通过像素检查；上传图片保留原色。 |
| 移除隐藏系统顶栏 | 删除开关与相关 Hook，清理旧值，交还宿主管理。 |
| 可关闭按键震动 | 独立开关，默认关闭；导航和独立按钮触发，自动刷新/收缩不触发。 |
| 倍速加入液态 | 倍速选择控制器与单元格加入分享面板材质，支持柔雾/清透，关闭恢复。 |
| 切换主页频道后全屏失效 | 横向偏移不再取消全屏适配，保留原生分页间距和触摸路径。 |
| 评论/分享展开时画面闪动 | 保留原生缩小/位移，直接合成视频变换；30 轮缩放与 frame 循环、109 个动画帧样本通过。 |
| 小屏宽屏不要放大 | 宽屏与方形视频保持原始大小和位置，仅扩展底部预留区域；竖屏仍可铺满。 |
| 增加居中收缩 | 左/右/中间三种位置；60%、80%、100% 尺寸及原生收缩/展开通过。 |
| 显示红果账号头像 | 读取原生账号侧栏头像，排除视频作者头像；内存缓存，账号图片更新后同步，退出登录清除。首次未获取时显示默认头像，打开一次红果侧栏可同步。 |
| 独立按钮功能自定义 | 搜索、首页、剧场、商城、我的、插件设置。头像只改变图案，点击仍执行所选动作；收缩圆钮点击展开底栏。 |

入口：液态外观 → 底栏外观与收缩；液态外观 → 分享、长按与倍速面板。

完整验证范围和未验证项见 [VALIDATION.md](VALIDATION.md)。真实采集 ZIP 与宿主 IPA 未包含在源码和发行包中。
