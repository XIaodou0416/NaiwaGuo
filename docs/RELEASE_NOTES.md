NaiwaGuo 0.0.5 预发布

- 首次使用的功能开关全部默认关闭，已保存的选择保留。液态兼容层自动检测系统：iOS 26 及以上启用，低版本不启用，无需手动操作。
- 移除隐藏系统状态栏功能与对应 Hook，清理旧设置，恢复宿主管理。
- 底栏新增按键触动反馈开关，默认关闭；点击导航和搜索按钮可轻震，自动刷新和收缩不触发。
- 修复底栏选中/未选中颜色设置，包括三种内容模式、收缩圆钮、搜索图标与颜色选择器实时更新；自定义图片保留原色。
- 宽屏与方形视频保留原尺寸和位置，不放大小屏视频；只扩展底部预留区域，保持竖屏全屏、翻页和原生控件点击。
- 修复横向切换频道时取消全屏适配的问题；尊重评论、分享面板的缩小与位移，避免临时恢复变换导致跳动。
- 倍速选择面板加入柔雾/清透液态，关闭时恢复原生背景。
- 底栏新增居中收缩；独立按钮可选搜索、首页、剧场、商城、我的、插件设置，可使用红果账号头像，退出登录清空缓存。

本地候选包包含 dylib/plist、rootful/rootless deb、源码、验证记录和 SHA-256。

GitHub 如后续发布，附件仅提供 dylib/plist、源码和 SHA-256，不上传 deb 或包含 deb 的整包。deb 仅在本地构建。验证见仓库 docs/VALIDATION.md。

**等待作者后续提供真机效果。** 当前截图为模拟器界面与合成背景；模拟器可验证反馈调用，无法证明真机触感。真实视频和低版本系统仍需补充测试，因此标记预发布。
