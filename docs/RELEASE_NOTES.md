# 奶蛙 0.1.0 私人候选版

- 恢复单色线性功能图标，移除墨绿强调色，深色界面自动使用白色。
- 重整六个功能分类，保留全文搜索和原生设置纯文字入口。
- 增加包含自定义图标及当前字体的文件备份与恢复，校验无效备份，替换前确认并保留宿主数据。
- 接入原 Naiwa HTTPS 后台，在同一管理台增加独立奶蛙统计。随启动自动上报红果 ID、红果/奶蛙/iOS 版本和随机安装编号，不设统计开关；首次打开设置显示一次数据说明。
- 缓存分类、复用分类单元格、移除位图重绘和无关效果刷新，测试专用代码不进入设备产物。
- 保留取消关注限制、发弹幕入口隐藏、底栏修复、分享/评论回退、赞助关闭选择和 iOS 15+。

每版完整源码独立备份，仓库保持私有。模拟器、真实 HTTPS 联调和最低 iOS 15 构建不代替用户真机验收。
