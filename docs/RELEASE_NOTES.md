NaiwaGuo 0.0.6 预发布

- 修复主页横向切换频道时，宿主重新写入底栏背景或透明度导致的整条黑底；关闭定制底栏时恢复宿主最近的状态。
- 统一账号头像展开和居中收缩时的内边距、图片比例；在相同尺寸设置下，头像不再收缩变小。
- 显式设置首页等所有项目的选中颜色，防止原生底栏后续覆盖为白色；自定义图片仍保留原色。
- 按要求撤回 0.0.5 针对评论、分享面板的视频变换合成与过渡处理，恢复此前策略；保留宽屏原尺寸修复。
- iOS 15–25 增加公开 UIKit 磨砂底栏，支持图标/文字、颜色、大小、头像与独立按钮动作；原生液态和自动收缩仅在 iOS 26+ 使用。

代码通过模拟宿主与系统 UIKit 检查，尚未在用户真机复测。低版本分支在 iOS 27 模拟器强制验证；不等同于 iOS 15 真机验收。

本地候选包包含 dylib/plist、rootful/rootless deb、源码、验证记录和 SHA-256。

本次未新建 GitHub Release。后续若发布，附件仅提供 dylib/plist、源码与校验和，不上传 deb 或包含 deb 的整包。
