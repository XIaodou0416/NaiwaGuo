# 奶蛙 0.0.9 私人候选版

- 完全取消关注和授权限制，删除账号和关注核验、关注请求、灰显及设置读取屏蔽。打开设置即可使用，重启后保留功能选择。
- 插件显示名称改为“奶蛙”，红果设置入口移除图标，只显示名称。
- 五个功能分类采用各自配色的方形图标，详情列表与搜索结果同步更新图标风格。

## 保留的 0.0.7 功能

- 新增隐藏主页发弹幕入口。
- 新增可永久关闭的赞助提示，使用原赞赏码和指定文案；赞助与功能解锁无关。
- 仓库设为私有，每次构建生成源码备份、文件清单和校验和，安装文件与私人源码分开。

保留 0.0.6 的底栏、头像、颜色修复、评论/分享过渡回退及 iOS 15+ 兼容分支。实际红果界面仍需用户真机验收。
