# 0.0.6 需求核对

本地候选版，2026-11-05。未发布 GitHub，未在用户真机复测。

| 需求 | 实现与验证 |
| --- | --- |
| 左右切换频道时底部黑色 | 在自定义底栏接管期间，拦住宿主原生底栏背景和子层透明度的再次写入；新插入的背景立即处理。100 次重绘、后插入背景、关闭恢复与无关视图检查通过。 |
| 头像展开/收缩比例不一致 | 统一 7pt 原始内边距及尺寸规则；以相同底栏和独立圆钮尺寸验证 60%、90%、100%，并在动画结束后测量实际头像像素。 |
| 首页选中黑色却仍白色 | 设置所有原生布局样式的选中颜色，保护显式颜色不被后续 tint 覆盖；四个项目及首页收缩/展开检查通过。上传图片保留原色。 |
| 撤回评论/分享闪动修复 | 移除 0.0.5 的特殊变换合成、无动画恢复和缩进画面例外，恢复之前策略；不再将旧版无闪动测试作为新版保证。 |
| iOS 15 及以上 | 最低部署 iOS 15，新增 API 使用可用性保护；15–25 使用公开 UIKit 磨砂底栏，26+ 使用原生液态与 iPhone 自动收缩。 |

低版本分支在 iOS 27 模拟器强制验证，不代表在 iOS 15 真机运行通过。完整结果与测试边界见 [VALIDATION.md](VALIDATION.md)。
