# 0.0.9 需求核对

| 用户要求 | 实现 |
| --- | --- |
| 取消只有关注才能用 | 删除账号/关系请求、关注调用、授权状态机、默认设置屏蔽和生命周期核验。列表可直接操作，运行效果使用真实保存值。 |
| 每个功能列表图标换 UI | 五类入口采用不同配色、白色符号的 36pt 方形图标；子列表及搜索使用统一的 30pt 图标。 |
| 设置外部入口删图标 | 宿主设置入口不再配置 image，只显示“奶蛙”；保留原生路由。 |
| NaiwaGuo 改中文 | 面板、原生入口、诊断产品名和 deb 显示名称改为“奶蛙”；内部标识与偏好键保留，便于升级。 |
| 保留之前功能 | 发弹幕入口隐藏、底栏修复、分享/评论处理回退、iOS 15+、赞助弹窗与不再提示选择保留。 |
| 私人维护与版本备份 | 仓库保持私有；当版源码 ZIP、版本、提交及 SHA-256 独立保存，不覆盖历史快照。 |

旧版 0.0.7/0.0.8 文档记录历史实现；其关注限制自本版起废止。

验证范围见 [VALIDATION.md](VALIDATION.md)。模拟器与最低系统构建不等同用户真机验收。
