# 0.1.1 开源源码版验证记录

日期：2026-11-13。此记录针对移除用户统计和服务器依赖后的源码，不沿用旧版的编译、模拟器或服务器联调结论。

## 已完成

- 源码检查：用户统计模块、后台、远程封禁和网络上报已移除；源代码中的外部网址仅为用户点击打开的交流群链接。
- macOS Foundation 实际运行测试：配置读取、旧服务缓存删除、重复清理、持久化结果、宿主凭据与用户设置保留均通过。
- Python 发布检查：版本一致、CONTRIBUTING 为空、README 旧更新段落删除、源码相对引用完整、无 Git 元数据的源码包可重复生成备份。
- Shell/Python 脚本语法检查。

## 未执行

当前机器只有 Command Line Tools，没有完整 Xcode、iPhoneOS SDK 和模拟器 SDK。最低 iOS 15 设备构建、iOS 模拟器回归和真机测试均未执行，不提供本次编译的二进制。

保留的设置、布局、字体、玻璃与调试模拟器测试需要在具备 Xcode 的机器运行；旧设置截图仅供参考。macOS 配置测试不替代 UIKit 或宿主兼容性验证。

## 源码分发

Release 提供当前源码 ZIP、文件哈希清单和 SHA-256。ZIP 不包含 .git 历史或维护备份。Git 克隆和源码 ZIP 均可生成本地源码备份；无 Git 元数据时使用导出清单中的提交号，未提供清单时如实记为未知。
