## 测试边界

真实 HTTPS 联调用合成账号，未读取真实用户记录。后台人数依据客户端上报 ID 去重，不能作为平台身份认证或实时在线人数。

尚未在用户真机复测红果账号接口、文件选择器、字体备份导入、频道切换、分享/评论、真实头像和震感。没有 iOS 15–25 运行时，仅完成最低部署构建及 iOS 27 强制公开 UIKit 磨砂分支，不能代替低版本真机结果。FLEXKing 外部集成和真实音频后端未端到端验证。

仓库保持私有，不创建公开 Release；每版完整源码独立备份，保留历史版本。完整数据见 [validation.json](validation.json)。
