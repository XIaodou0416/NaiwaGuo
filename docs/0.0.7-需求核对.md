# 0.0.7 需求核对

- 主页发弹幕入口：独立隐藏开关，可恢复，不隐藏弹幕内容。
- 仓库：已设置为 private；以后每个新版本单独保留私人源码备份和校验和。
- 关注限制：作者 ID 106173406210，未验证关注前禁用插件功能与设置列表；保留原有选择。
- 原生核验：SSUgcApiService 的 getUserRelation:completion:，回调先错误、后响应；严格核对返回作者 ID，使用宿主模型判断关注类型。
- 确认关注：仅在明确点击“确认关注”后调用 SSShortVideoFollowUserManager，完成后重新查询，不能凭点击或本地缓存解锁。
- 重复核验：启动、回到前台、重新打开设置和账号变化；过期请求不能解锁另一个账号。
- 赞助提示：保留用户指定文案与原赞赏码，提供“直接关闭”“以后再也不弹”；赞助不是使用门槛。

模拟测试与真实服务器验收的范围见 VALIDATION.md。接口信息来自用户提供宿主版本的本地元数据检查，不在备份内包含宿主二进制或私人诊断资料。
